# Project Guidelines

## Publishing
- After each successful development task, run the relevant checks before committing and pushing the completed changes to the `main` branch on `origin`.
- Do not commit or push changes when checks fail or when sensitive information, credentials, private keys, or customer-submitted data may be included. Report blockers instead.
- Never put GitHub credentials or tokens in project files or commit messages.
- After publishing, report the changes and the commit to the user.
